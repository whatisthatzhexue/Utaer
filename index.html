UTA·ER

一款面向日语学习者与歌曲爱好者的 Web 端轻量工具，聚焦日语演唱中的 声调（アクセント） 与 情感表达。

功能一览

声调怎么读、唱得准不准——打开就能看到。

01
录音 / 上传音频

录下来，或直接上传；剩下的交给 Utaer。

02
声调曲线对照

演唱音高与词典调型同屏对比，哪一拍高了、低了，一目了然。

03
振假名 · 罗马音

同一段歌词，可切换原文、振假名与罗马音三种读法。

04
情感标签

输出整体情感与可信度，唱得开不开心，让它告诉你。

05
分词与解析

逐词展示词性、读音与释义，附语法点说明。

06
面向学习者

初学者用得上，爱好者用得更顺。

关于

每一个读音与声调，都有依据。

Utaer 把“学术级”的日语语言与声学能力，放进一个轻量 Web 工具里。

01
语言引擎

词性、读音与声调，来自权威词典 UniDic。

02
声学分析

用 Praat 提取你的音高轨迹，与词典调型同屏对照。

03
情感识别

识别歌唱情感，并说明判断的依据。

04
数据链路

Supabase 云端：分析任务与音频文件，安全存储与回传。

05
罗马音引擎

内置罗马音引擎，处理好促音、长音与外来语。

06
声调规范

audio_accent.json：统一的声调数据结构。
