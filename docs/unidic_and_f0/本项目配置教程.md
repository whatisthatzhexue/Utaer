# 本项目配置教程

> 本教程完成 Utaer 项目 unidic_and_f0 部分在 WSL 宿主上的 Python 环境、MeCab 依赖、环境变量与词典路径配置，使 `functions/unidic/init.py` 可以运行。

## 1. 文档简介

`tdmelodic 配置教程.md` 负责把 tdmelodic 及其组合词典装好；本教程负责把**项目自身**的宿主环境配好：`init.py` 需要宿主可用的 mecab-python3、组合词典路径，以及项目约定的 `test.env` 环境变量。

建议阅读顺序：`tdmelodic 配置教程.md` → `tdmelodic 使用教程.md`（可选）→ 本教程 → `本项目 unidic_and_f0 部分启动教程.md`。

## 2. 前置条件

### 2.1 环境与软件要求

- 已完成 `tdmelodic 配置教程.md`，且组合词典已安装在 `$(mecab-config --dicdir)/tdmelodic`。
- WSL2（Ubuntu-22.04），自带 python3 与 git。

### 2.2 文件与路径约定

- 项目根目录须包含 `test.env`（开发期环境变量文件，允许提交）与 `functions/unidic/` 下的 `init.py`、`td_service.py`、`Dockerfile`。
- 第三方仓库（`tdmelodic/`、`mecab-unidic-neologd/`）与 UniDic 基础辞书须已按 `tdmelodic 配置教程.md` 自行安装。

### 2.3 前置文档依赖

- `tdmelodic 配置教程.md`（必读前置）。
- 项目总规范 `AGENTS.md` §6（`test.env` 路径约定）。

## 3. 核心步骤

### 3.1 安装 pip

```bash
sudo apt update
sudo apt install python3-pip
```

### 3.2 安装 mecab-python3

```bash
pip install mecab-python3
```

> **说明**：安装后在 Python 中以 `import MeCab` 使用（对应 `init.py` 的写法）。

### 3.3 补全 mecab 相关包

```bash
sudo apt install -y mecab libmecab-dev mecab-ipadic-utf8
```

> **说明**：`libmecab-dev` 是 mecab-python3 的编译/运行依赖；`mecab-ipadic-utf8` 提供系统默认词典（不指定 `-d` 时使用）。

### 3.4 建立 mecabrc 软链接

```bash
sudo mkdir -p /usr/local/etc && sudo ln -s /etc/mecabrc /usr/local/etc/mecabrc
```

> **说明**：mecab-python3 运行时会在 `/usr/local/etc/` 下查找 mecabrc 配置文件，而系统 mecab 的配置位于 `/etc/mecabrc`，因此建立软链接指向它。

### 3.5 PATH 配置（可省略）

```bash
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
```

> **说明**：使 pip 用户级安装的可执行文件能被直接调用。

### 3.6 环境变量与路径约定（test.env）

项目根目录的 `test.env`（后缀即 `env`）内容：

```ini
TEST_USER_ID=testuser123
TEST_AUDIO_ID=20030303123749
TEST_SAVE_PATH=fast-api\audio\
```

约定（总 AGENTS.md §6）：

- `functions/` 下各独立功能只需读取这三个值，拼接为 `fast-api\audio\testuser123\20030303123749\` 即为开发期处理后文件的保存路径。
- `TEST_AUDIO_ID` 采用「日期 + 6 位随机数」格式（如 `20030303123749`），与 Supabase Storage 布局一致。
- 后续接入 fast-api / supabase 时，只需修改引用这三个值所在区域的代码。
- 保存路径一律引用 `test.env`，禁止硬编码路径。

### 3.7 词典路径确认

```bash
mecab-config --dicdir
```

输出即 MeCab 词典根目录（如 `/usr/lib/x86_64-linux-gnu/mecab/dic`）。`init.py` 的 `load_t()` 会在该目录下拼接 `/tdmelodic`，因此组合词典必须位于 `<dicdir>/tdmelodic`。确认：

```bash
ls $(mecab-config --dicdir)
```

输出中应包含 `tdmelodic` 目录。

## 4. 验证方式

### 4.1 Python 绑定验证

```bash
python3 -c "import MeCab; print(MeCab.Tagger().parse('すもももももももものうち'))"
```

预期：正常输出若干行「表層形<Tab>品詞…」的分词结果（使用默认 ipadic 词典），无报错即表示 mecab-python3 安装成功。

### 4.2 词典路径验证

```bash
mecab-config --dicdir
ls $(mecab-config --dicdir)
```

预期：第一条命令输出词典根目录路径；第二条命令的输出中包含 `tdmelodic`。

## 5. 常见问题 / 排错

| 症状 | 原因 | 解决方案 |
|---|---|---|
| `pip: command not found` | python3-pip 未安装 | 回到 3.1 |
| `pip install mecab-python3` 编译失败 | 缺少 libmecab-dev | 先执行 3.3 再重试安装 |
| `import MeCab` 报 mecabrc 相关错误 | 软链接缺失 | 回到 3.4 |
| `Permission denied` | 需要管理员权限的步骤未加 sudo | 检查 3.3、3.4 的 sudo |
| `ls $(mecab-config --dicdir)` 无 `tdmelodic` | 组合词典未安装 | 完成 `tdmelodic 配置教程.md` 3.16 |
