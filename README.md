## 项目概述

**Utaer（无他耳）** 是一款面向日语学习者与歌曲爱好者的 Web 端轻量工具，聚焦日语演唱中的**声调（アクセント）**与**情感表达**。产品以日本国立国语研究所开发的权威词典 **UniDic** 为事实底座，将日语“相对高低”的声调信息转化为高拍/低拍/降调位置的可视化卡片，并支持用户上传演唱音频，提取音高轨迹、识别整体情感（喜悦/悲伤/激昂等），结合词典调型给出面向普通人的纠音提示与简评。

项目坚持 **“权威资源给事实，AI 给解释”** 的分工原则：
- 词性、调型等事实性信息直接由 UniDic 呈现，杜绝大模型“自信答错”的音调幻觉；
- 大语言模型仅承担演唱分析与语料数据的通俗解释任务，结果可溯源。

## 项目优势

- **权威基座**：UniDic 由日本国立国语研究所开发，是日语 NLP 领域公认的权威词典，截至 2026 年仍在积极更新。
- **对抗幻觉**：通用文字类 LLM 的训练语料以文本为主，声调信息稀缺，常因黑盒效应给出错误音调。Utaer 以 UniDic 事实数据为优先，从源头杜绝误导。
- **学术支持**：项目中日语相关知识准确度由**大连理工大学外国语学院教师**参与校准，技术基础与知识基础均有保障。
- **渐进路线**：从轻量 MVP 起步，逐步接入语料库与社区功能，成长路径清晰。

## 为什么选择这个方向？

| 方向 | 决策 |
|------|------|
| **翻译** | AI 竞品众多，且专业翻译需人工介入，大学生团队难以胜任 |
| **句法分析** | 用户理解门槛高，学习成本大 |
| **词性标注** | 可展示给用户，但交付 AI 的实用价值低 |
| **声调识别** | 日语声调仅为前后对比的相对高低，一维信息，易于量化且有分析抓手 |

---

## 路线规划

| 阶段 | 目标 |
|------|------|
| **早期（MVP）** | UniDic 词性+声调查询 + LLM 声调偏离检测 / 情感识别 |
| **中期（语料库接入）** | 接入中納言，提供词汇频度、搭配、类似表达等数据洞察 |
| **后期（社区生态）** | 建立用户歌唱作品社区，众包语料，经用户授权后支持个性化推荐 |
