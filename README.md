# Utaer
Utaer是一款面向日语学习者与歌曲爱好者的Web端轻量工具，以日本国立国语研究所开发的权威词典UniDic为事实底座，将日语的“相对高低”声调信息转化为高拍/低拍/降调位置的可视化卡片，并支持用户上传演唱音频，提取音高轨迹、识别整体情感（喜悦/悲伤/激昂等），结合词典调型给出面向普通人的纠音提示与简评。项目坚持“权威资源给事实，AI给解释”的分工原则：词性、调型等事实性信息直接由UniDic呈现，杜绝大模型“自信答错”的音调幻觉；大语言模型仅承担演唱分析与语料数据的通俗解释任务，结果可溯源。产品早期聚焦歌词取词、声调查询和演唱自评闭环，中期接入语料库（如中納言）提供词频与搭配查询，后期建设用户社区，形成“内容—评价—数据”的良性循环。
